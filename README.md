# Moovice

A movie and TV discovery app built with React, React Router and the TMDB API. No backend - everything runs client-side against TMDB directly.

## Features

- Trending, popular, top rated, now playing and upcoming movies and TV shows
- Full movie and TV detail pages with cast, trailers, budget/revenue, similar and recommended titles
- Person pages with biography and known-for credits
- Multi-search across movies, TV shows and people
- Browse by genre with sorting and pagination
- Favorites stored locally in the browser

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
